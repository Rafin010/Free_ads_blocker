# Free Blocker 🛡️

A fast, lightweight, modern, secure, scalable, and production-ready Chromium browser extension that gives users complete control over blocking advertisements and unwanted content.

## Features

- **Ad Blocking:** Comprehensive ad blocking using Manifest V3 declarativeNetRequest API.
- **YouTube Ad Blocker:** Skips pre-roll ads and removes overlays on YouTube.
- **Privacy Protection:** Blocks trackers and manages cookie banners.
- **Security:** Blocks known malware, phishing, and scam sites.
- **Adult Content Filter:** Optional blocking of adult sites and videos.
- **Modern UI:** Premium glassmorphism design with Dark/Light mode support.
- **Performance:** Optimized CPU/Memory usage with CSS cosmetic filters and DNR rules.
- **Cloud Sync:** FastAPI backend for syncing settings across devices.
- **Referral Program:** Invite friends to unlock Premium features.

## Project Structure

- `extension/`: The complete Manifest V3 browser extension.
- `backend/`: FastAPI backend for user accounts, sync, and referrals.
- `docs/`: Comprehensive documentation.
